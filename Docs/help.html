MediaPlayer X-Ark ヘルプ

このヘルプでは、最初に再生するまでの手順から、音量補正、MIDI、CD、スキン、プラグインなどの詳細設定まで確認できます。 まず使い始める場合は「最初にやること」から、特定機能を確認したい場合は左の検索欄か目次を使ってください。

ファイル / URL 再生 CD / CUE / MIDI DSP / GEQ / ReplayGain スキン / Discord / プラグイン 単一 HTML / オフライン対応

まず再生したい

右クリックメニューの 開く、またはファイルのドラッグ＆ドロップから始めます。URL ストリームも右クリックメニューから開けます。

音を整えたい

ReplayGain、Graphic Equalizer、DSP、クロスフェード、NonStopMix を用途ごとに使い分けます。

対応範囲を広げたい

MIDI レンダラー、サウンドフォント、コーデックプラグイン、関連付け設定を確認してください。

全体像

MediaPlayer X-Ark は Windows 向けのデスクトップメディアプレイヤーです。 音楽ファイルの再生、プレイリスト管理、CD 再生、CUE シート展開、MIDI 再生、エフェクト、スキン、Discord 連携、プラグイン拡張に対応します。

主な操作入口

  • 右クリックメニュー: 開く、URLを開く、再生操作、設定、エフェクト、イコライザ
  • プレイリスト画面: 曲の追加、削除、並べ替え、保存
  • 設定画面: 一般、再生、表示、出力、スキン、CDDB、プラグイン

このヘルプの読み方

  • 初回利用: 「最初にやること」と「基本操作」
  • 音質・音量: 「ReplayGain」「エフェクト」「Graphic Equalizer」
  • 特殊メディア: 「CD」「CUEシート」「MIDI」
  • 問題解決: 「困ったとき」

最初にやること

ローカルファイルを再生する

  1. メイン画面で右クリックし、開く (&O) を選びます。
  2. 音声ファイル、プレイリスト、または .cue ファイルを選びます。
  3. ファイルやフォルダをメイン画面へドラッグ＆ドロップして開くこともできます。

URL ストリームを再生する

  1. 右クリックメニューから URLを開く (&R) を選びます。
  2. http:// または https:// で始まる URL を入力します。
  3. 確定すると、その URL の再生を開始します。
おすすめ: 日常利用では、一般設定の「前回のプレイリストを復元する」「前回の再生位置から再開する」を先に確認すると便利です。

基本操作

操作内容
再生 / 一時停止現在の曲の再生状態を切り替えます。
停止再生を停止します。
前へ / 次へプレイリスト内の前後の曲へ移動します。
シークトラックスライダーまたはショートカットで再生位置を変更します。
ランダムプレイリストの再生順をランダムにします。
ループ通常、1曲リピート、全体ループなどの再生モードを切り替えます。
スリープタイマー右クリックメニューから 15分 / 30分 / 60分後の停止を設定できます。

ショートカット

キー操作
Space再生 / 一時停止
Left / Rightシーク
AAB リピートの開始点を設定
BAB リピートの終了点を設定
CAB リピートを解除
ショートカットは画面やフォーカス状態によって効き方が変わる場合があります。確実に使う場合はメイン画面を前面にしてください。

プレイリスト

プレイリスト画面では、曲の追加、削除、上下移動、保存、読み込みができます。

  • 複数ファイルをまとめて開くと、プレイリストへ追加できます。
  • CUE シートを開いた場合は、トラック単位に展開されます。
  • 一般設定で、終了時のプレイリスト保存や起動時の復元を調整できます。

表示とミニプレイヤー

メイン画面ではタイトル、時間、カバーアート、スペクトラム、ウェーブフォームなどを表示します。

  • スペクトラム表示はクリックや設定で表示モードを切り替えられます。
  • ミニプレイヤー対応スキンでは、メイン画面を隠して小型表示に切り替えられます。
  • ファイル情報画面ではタグ情報やカバーアートを確認できます。

対応形式

一般的な音声ファイル、MIDI、CUE、プレイリストに対応します。追加形式はコーデックプラグインで拡張できます。

種類例補足
音声ファイルMP3, FLAC, WAV, OGG など環境やプラグインにより対応範囲が変わります。
MIDIMID, MIDI, RMI, KARレンダラーとサウンドフォント設定を確認してください。
CUE.cue長い音声ファイルをトラック単位に展開します。
追加 codecSRLA, WMA, MP4 系など同梱または追加 DLL により対応します。

エフェクト

DSP エフェクトは、音に加工を加えるための機能です。効果を強くしすぎると音割れや聴き疲れにつながるため、少しずつ調整してください。

  • リバーブ、エコー、コンプレッサー、ディストーションなどを用途に応じて切り替えます。
  • 設定値は曲や音源によって最適値が変わります。
  • 音量差が気になる場合は、エフェクトより先に ReplayGain を確認してください。

Graphic Equalizer

12 バンドの Graphic Equalizer で、低域から高域までのバランスを調整できます。

帯域主な印象
低域重低音、キック、ベースの量感
中域ボーカル、ギター、ピアノなどの聴こえ方
高域抜け、空気感、シンバルなどの明るさ
注意: 複数バンドを大きく上げるとクリップしやすくなります。上げるより、不要な帯域を下げる調整も試してください。

ReplayGain

ReplayGain は、曲ごとの音量差を自動補正する機能です。寄せ集めのプレイリストやアルバムをまたいだ再生で音量差を抑えたいときに使います。

項目使い方
Track各トラック単位で音量をそろえます。複数アルバムを混ぜて再生する場合に向いています。
Albumアルバム内の音量バランスを維持します。アルバムを通して聴く場合に向いています。
プリアンプReplayGain 適用後の全体音量を追加調整します。
ReplayGain を使うには、音声ファイル側に ReplayGain タグが必要です。タグがない曲では補正できません。

AB / クロスフェード / NonStopMix

AB リピート

曲の一部を繰り返す機能です。A で開始点、B で終了点、C で解除します。語学学習や演奏練習に向いています。

クロスフェード

曲の切り替わりで、前の曲をフェードアウトしながら次の曲をフェードインします。再生設定で有効化し、フェード時間を調整します。

NonStopMix

次の曲を事前に準備して、曲間を自然につなげるための機能です。ギャップレス再生に近い聴き方をしたい場合に使います。

組み合わせの注意: NonStopMix とクロスフェードは考え方が異なるため、同時に使う前提ではなく用途に応じて切り替えてください。

CD

オーディオ CD の再生、プレイリスト追加、メタデータ取得、リッピングに対応します。

  1. CD をドライブへ入れます。
  2. CD 画面でドライブを選び、TOC を読み込みます。
  3. トラック一覧を確認し、再生またはプレイリストへ追加します。
  4. 必要に応じて CDDB / MusicBrainz から曲名やアルバム情報を取得します。
リッピング機能を使う場合は、保存形式や保存先を確認してください。環境やディスク状態によって読み取りに時間がかかる場合があります。

CUEシート

.cue ファイルを開くと、1つの音声ファイルを複数トラックとして扱えます。

  • シングルファイル型、マルチファイル型の CUE に対応します。
  • 展開後は通常のプレイリスト項目として再生できます。
  • ライブ盤や連続録音の管理に向いています。

MIDI

MIDI は、選択するレンダラーとサウンドフォントによって音が変わります。標準では XArkMidiEngine を利用でき、外部 DLL がある場合は FluidSynth や BASSMIDI も選択できます。

レンダラーサウンドフォント補足
XArkMidiEngineDLS / SF2標準搭載。追加作業なしで利用できます。
FluidSynthSF2対応 DLL を配置した環境で利用できます。
BASSMIDISF2bass.dll と bassmidi.dll が必要です。
FMODDLS他の経路が使えない場合のフォールバックとして扱われます。

自動選択の考え方

自動設定では、利用可能なレンダラーを探して使用します。サウンドフォントを指定しない場合は Windows 標準の gm.dls を使う構成になります。

一般設定

項目内容

前回の再生位置から再開する途中停止した曲の位置を引き継ぎます。
プレイリストを自動保存する終了時にプレイリストを保存します。
常に最前面に表示するメインウィンドウを他のウィンドウより前に表示します。
ファイルを開いた時の動作開いたファイルをすぐ再生するか、追加のみかを選びます。

スキン

スキン設定では、UI の外観を変更できます。スキンファイルを選び、Name / Author / Description などの情報を確認して適用します。

  • メイン画面の見た目を変更します。
  • 対応スキンではプレイリストやミニプレイヤーの見た目も変わります。
  • 表示設定とは別に、スキンより優先する表示項目を指定できます。

CDDB

CD のアルバム名、曲名、アーティスト名などを取得するための問い合わせ先を管理します。

  • 問い合わせ URL の追加 / 削除 / 並べ替え
  • gnudb / FreeDB と MusicBrainz の優先順位
  • デフォルト設定への復帰

プラグインと関連付け

コーデックプラグイン

FMOD コーデックプラグイン DLL を追加することで、対応形式を拡張できます。プラグインは Plugins/ フォルダへ配置し、アプリケーションを再起動または再スキャンして読み込み状態を確認します。

プラグイン対応形式
codec_srla.dllSRLA 形式
codec_wma.dllWMA 形式。環境差を避けるため別途用意されています。
codec_mp4.dll など追加プラグインは FMOD-PLUGINS 側から取得します。
注意: プラグインはアプリのビット数に合ったものを使ってください。合わない DLL は読み込めません。

関連付け

Windows 上で対応拡張子を X-Ark に関連付けるための設定です。管理者権限が必要な場合は、案内に従って権限を上げてください。

Discord連携

Discord Rich Presence を有効にすると、再生中の曲情報を Discord のステータスに表示できます。

項目内容
Discord Rich Presence を有効化再生中の情報を Discord へ送信します。
アプリケーション IDDiscord Rich Presence を使うために必須です。利用者自身で用意した Discord Application ID を入力します。
注意: アプリケーション ID が未設定の場合、Discord Rich Presence を有効にしても連携は利用できません。

表示対象には、トラックタイトル、アーティスト名、アルバム名、再生状態などが含まれます。

困ったとき

症状確認ポイント
音が出ない出力方式、出力デバイス、音量、ミュート状態を確認してください。
MIDI が鳴らないレンダラー、サウンドフォント形式、追加 DLL の配置を確認してください。
追加形式が開けない必要なコーデックプラグインが配置され、読み込まれているか確認してください。
CD 情報が取れないCDDB 設定、ネットワーク接続、ディスクの読み取り状態を確認してください。
曲間が不自然クロスフェードと NonStopMix のどちらを使うか整理してください。
音量差が大きいReplayGain タグの有無、Track / Album モード、プリアンプ設定を確認してください。
このヘルプは、利用者向けの読みやすさと機能項目の探しやすさを重視しています。
