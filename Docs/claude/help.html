MediaPlayer X-Ark

Windows向け高機能メディアプレイヤー。FMODエンジン搭載、豊富なエフェクト・CD対応・スキンカスタマイズ対応。

概要

MediaPlayer X-Ark は .NET 9.0 / Windows Forms で構築された Windows デスクトップ向けオーディオプレイヤーです。コアに FMOD エンジンを採用し、高品質な再生と多彩なDSPエフェクトを実現します。

🎵

多彩なフォーマット対応

MP3, FLAC, WAV, OGG, MIDI, トラッカー形式など30種類以上に対応。コーデックプラグインで拡張可能。

🎛️

12種類のDSPエフェクト

イコライザー、リバーブ、エコー、コンプレッサーなど。プリセット保存・読み込み対応。

💿

CD取り込み

Win32 IOCTL によるCDDA読み取り。CDDB / MusicBrainz 自動メタデータ取得対応。

🎨

スキンシステム

XML ベースの .xsk スキンファイルによりUIを自由にカスタマイズできます。

📊

ビジュアライザー

FFTスペクトラム解析と波形表示。スノーブロックエフェクト付き。

🎮

Discord連携

Rich Presence で再生中の曲情報をDiscordに表示できます。

クイックスタート

ファイルを再生する

  1. メイン画面上で右クリック → 開く (&O) を選択してファイルを開きます。
  2. または、ファイルエクスプローラーからウィンドウへドラッグ＆ドロップします。
  3. メディアキーまたは Space で再生を開始します。

URLストリームを再生する

  1. 右クリックメニュー → URLを開く (&R) を選択。
  2. ストリームURLを入力してOKを押します。
ヒント: 起動時に前回のプレイリストと再生位置を自動復元できます。設定 → 一般 で有効化してください。

音量・パン

音量

音量スライダー（Vol）で 0 ～ 150% の範囲で調整できます。100% が原音量です。150% まで上げることでブースト再生が可能です。

↑ / ↓ キーでも ±5 単位で調整できます。

パン (Pan)

パンスライダーで左右の音量バランスを調整します。中央位置 (0) がステレオ標準です。

  • 左方向: 左チャンネルを強調 (-10 ～ 0)
  • 右方向: 右チャンネルを強調 (0 ～ +10)

プレイリスト

メイン画面のプレイリストボタン、または右クリックメニュー → プレイリスト (&L) でプレイリストウィンドウを開きます。

  • ファイルをドラッグ＆ドロップ（フォルダごとドロップも可能）
  • 右クリックメニュー → 開く でファイル選択
  • M3U / PLS 形式のプレイリストファイルを開く

プレイリストの保存・読み込み

自動保存: 設定で「プレイリストを自動保存する」を有効にすると、アプリ終了時にプレイリストが保存され、次回起動時に復元されます。

エフェクト

右クリックメニュー → エフェクト (&E) でエフェクトパネルを開きます。各エフェクトは個別に有効化/無効化できます。

利用可能なエフェクト一覧

エフェクト主なパラメータ説明

周波数変更 Frequency (Hz) 再生周波数を直接変更（速度と音程が同時に変わります）
ディストーション Level 音を歪ませるエフェクト。ギター系サウンドに
コーラス Mix (%)、Rate (Hz)、Depth 音に広がり・厚みを付加するモジュレーション系エフェクト
エコー Delay (ms)、Feedback (%)、Dry/Wet 山びこのような反響効果を付加
フランジャー Mix (%)、Rate (Hz)、Depth ジェット機のような独特のうねり効果
ハイパスフィルター CutOff (Hz)、Resonance 指定周波数以下の低音をカット
ローパスフィルター CutOff (Hz)、Resonance 指定周波数以上の高音をカット

スピード機能

CD機能

右クリックメニュー → CDドライブを選択して CD ウィンドウを開きます。

基本操作

  1. CDをドライブに挿入します。
  2. CDウィンドウでドライブを選択します。
  3. TOC（トラック情報）が自動的に読み込まれます。
  4. CDDB / MusicBrainz からメタデータ（アーティスト・アルバム・トラック名）を自動取得します。
  5. トラックを選択して再生、またはCD取り込みを実行します。

CD取り込み

CDトラックをファイルとして保存します。Win32 IOCTL 経由でセクタを直接読み取るため、高精度な取り込みが可能です。

CDDB / MusicBrainz 設定

設定 → CD/CDDB で以下を設定できます。

  • CDDBサーバーの追加・変更（複数サーバー登録可能、自動フォールバック対応）
  • MusicBrainz を優先的に使用するオプション

CUEシート対応

CUEシート (.cue) ファイルを開くことで、1つの音声ファイルに含まれる複数トラックを個別に再生できます。

使用方法

  1. .cue ファイルを MediaPlayer X-Ark で開きます。
  2. プレイリストにCUEシートの各トラックが展開されて追加されます。
  3. 通常のトラックと同様に再生・管理できます。

対応CUEシート形式

  • シングルファイル形式（1つの音声ファイル + CUEシート）
  • マルチファイル形式（複数の音声ファイル + CUEシート）

ビジュアライザー

スペクトラムアナライザー

FFT解析による周波数スペクトラムをリアルタイムで表示します。専用の描画スレッドでスムーズなアニメーションを実現しています。

  • スペクトラム表示モードを複数から選択可能（設定 → 表示）
  • スノーブロックエフェクト: スペクトラムの降雪風ブロックアニメーション（設定で有効化）

波形表示

トラックの全体波形をウィンドウ下部に表示します。波形上をクリックすることで任意の位置にシークできます。

波形はバックグラウンドで解析されます。長い楽曲の場合、完全な波形表示まで少し時間がかかることがあります。

ミニプレイヤー

コンパクトなミニプレイヤーモードで使用できます。

  • Escape キー または メニュー → 最小化 (&X) で切替
  • 基本的な再生コントロールを小さなウィンドウで操作可能
  • 画面端に寄せてコンパクトに使用するのに最適

ReplayGain

楽曲間の音量差を自動補正する機能です。異なるアルバムの曲を続けて再生するときの音量のバラつきを抑えます。

設定

設定説明
ReplayGain を有効化ReplayGain 補正を適用する
モード: Track各トラック単位で音量を正規化（プレイリスト混在時に適している）
モード: Albumアルバム全体の音量バランスを維持して正規化
プリアンプReplayGain 適用後の追加ゲイン調整 (-6 ～ +6 dB)
前提条件: ReplayGain を利用するには、音声ファイルに ReplayGain タグが書き込まれている必要があります。タグはサードパーティツール（例: foobar2000 の ReplayGain Scanner）で書き込めます。

AB リピート

楽曲の特定区間を繰り返し再生する機能です。語学学習や演奏練習に便利です。

使用方法

  1. 繰り返したい区間の開始位置で A キーを押して A 点を設定
  2. 繰り返したい区間の終了位置で B キーを押して B 点を設定
  3. A 点から B 点の区間が自動的に繰り返し再生されます
  4. C キーで AB リピートを解除します

クロスフェード

トラック切替時に前の曲をフェードアウトしながら次の曲をフェードインさせる機能です。DJ ミックスのような連続再生が実現できます。

設定 → 再生 → クロスフェード でオン/オフと時間 (1～15秒) を調整できます。

NonStopMix との組み合わせ: NonStopMix はクロスフェードと排他です。用途に応じてどちらか一方を選択してください。

NonStopMix

次の曲を再生中に事前ロードし、トラック境界でそのまま接続するギャップレス再生機能です。

MIDI エンジン

MIDI ファイルの再生に使用するエンジンを設定 → 出力 → MIDI レンダラー で選択できます。標準では XArkMidiEngine が使用されます。FluidSynth や BASSMIDI はライブラリを別途配置することでユーザーが導入できます。

エンジンサウンドフォント対応導入方法
XArkMidiEngine（標準）DLS / SF2標準搭載。追加作業不要
FluidSynthSF2別途 libfluidsynth.dll を配置
BASSMIDISF2別途 bass.dll / bassmidi.dll を配置
FMOD（自動フォールバック）DLS（Windows 標準）上記ライブラリが全て不在の場合のみ使用
サウンドフォント対応形式: XArkMidiEngine は DLS・SF2 の両方に対応します。FluidSynth・BASSMIDI は SF2 のみ対応です。 サウンドフォントを指定しない場合は Windows 標準の gm.dls を使用します。

エンジン選択の優先順位

「自動」設定の場合、利用可能なライブラリを以下の順で検索して使用します。

  1. XArkMidiEngine
  2. BASSMIDI
  3. FluidSynth
  4. FMOD（フォールバック）

  3. 設定 → プラグイン で読み込み状態を確認できます。
