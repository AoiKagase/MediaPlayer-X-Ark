MediaPlayer X-Ark ヘルプ

この文書は、現在のコードベースに存在する画面名・設定名・機能に合わせて書き直したヘルプです。 「何ができるか」よりも「どこで操作するか」と「どう使い分けるか」を優先してまとめています。

FMOD ベース再生 DSP / GEQ / ReplayGain CD / CUE / MIDI 対応 表示設定とスキン切替 単一 HTML / オフライン完結

最短で再生したい

右クリックメニューの 開く か、ファイルのドラッグ＆ドロップで開始できます。URL ストリーム再生も別メニューで用意されています。

設定を把握したい

設定画面は 一般 / 再生 / 表示 / 出力 / スキン / CDDB / プラグイン を中心に構成されています。実際の画面構成に沿って追いやすい並びです。

音を追い込みたい

Graphic Equalizer、各種DSP、ReplayGain、クロスフェード、NonStopMix を個別に使い分けられます。

全体像

MediaPlayer X-Ark は Windows 向けのデスクトッププレイヤーです。再生コアは FMOD を使用し、 プレイリスト管理、DSP エフェクト、Graphic Equalizer、CD 読み込み、CUE 展開、MIDI 再生、スキン切替を一通り備えています。

11+個別DSPエフェクト
12 BandGraphic Equalizer
CD / CUEディスク系メディア対応
FMOD + MIDI複数レンダラー構成

このヘルプが重視していること

  • 実際のメニュー名、設定名、画面名に合わせること
  • 初心者が最初の 5 分で使えること
  • 設定項目の位置関係を追いやすくすること

主な起点

  • 右クリックメニュー: 再生、設定、エフェクト、イコライザ、URL、プレイリスト
  • 設定画面: ツリー形式で各機能へ移動
  • キーボード: 再生、シーク、AB リピート、音量、モード切替

最初にやること

まずは通常のファイル再生、URL 再生、プレイリストの基本だけ押さえれば十分です。

ローカルファイルを再生する

  1. メイン画面上で右クリックし、開く (&O) を選びます。
  2. 音楽ファイル、プレイリストファイル、または .cue を選択します。
  3. より素早く使う場合は、ファイルやフォルダをそのままウィンドウへドラッグ＆ドロップします。

URL ストリームを再生する

  1. 右クリックメニューから URLを開く (&R) を選びます。
  2. ストリーム URL を入力して確定します。
  3. URL 再生は通常のプレイリスト追加とは別扱いで、その場で再生されます。
開始地点としておすすめ: 先に 一般設定 で「前回のプレイリストを復元する」「前回の再生位置から再開する」を調整すると、日常利用がかなり楽になります。

基本操作

メイン操作は右クリックメニューとキーボードショートカットの両方から使えます。

操作場所内容
再生 / 一時停止 / 停止右クリックメニュー、キー操作基本の再生制御です。停止すると通常は先頭に戻ります。
前へ / 次へ右クリックメニュー、キー操作プレイリストの前後トラックへ移動します。
シーク← / →再生位置を前後に移動します。
再生モード右クリックメニューの再生モードNormal / Random / Repeat / Loop を切り替えます。
スリープタイマー右クリックメニューのスリープタイマー15分後、30分後、60分後、キャンセルを選べます。

再生モードの使い分け

  • Normal: プレイリストを順番に再生
  • Random: シャッフルキューでランダム再生
  • Repeat: 現在曲の反復再生
  • Loop: プレイリスト全体のループ

日常用途の定番

  • 作業BGM: Random または Loop
  • 語学学習: AB リピート
  • 寝る前: スリープタイマー 30分 or 60分

プレイリスト

右クリックメニューの プレイリスト (&L) からプレイリスト画面を開閉します。 プレイリストは単なる再生順リストではなく、CUE 展開、並び替え、保存、位置復元の中心です。

追加方法

  • ファイルまたはフォルダをドラッグ＆ドロップする
  • 開く から追加する
  • .m3u / .m3u8 / .pls を開く
  • .cue を開いてトラック展開する

代表的な操作

操作結果
ダブルクリック選択したトラックを即再生します。
右クリックから削除 / 移動曲順の整理や不要曲の除外を行います。
並び替えファイル名、タイトル、アーティストなどで整理できます。
保存プレイリストを M3U 系形式で保存できます。
実用上のポイント: 一般設定でプレイリスト自動保存と前回復元を有効にすると、アプリ再起動後も前の作業状態を引き継げます。

表示とミニプレイヤー

X-Ark は見た目の調整幅が比較的大きく、表示設定とスキン設定の役割を分けて使うのがコツです。

スペクトラム表示

  • デフォルトモードを選択可能
  • SnowBlock モードを有効化可能
  • 更新間隔、落下速度、バー色を調整可能

ウェーブフォーム

  • 左右チャンネル、ミックス、再生済み、未再生の色を設定可能
  • 設定値をスキンより優先するオプションあり

Escape またはメニューの 最小化 (&X) を使うと、スキンが対応している場合はミニプレイヤー表示へ、 対応していない場合はタスクトレイ中心の動作に切り替わります。

対応形式

標準対応形式に加えて、MIDI レンダラーや FMOD codec プラグインの有無で実際の再生範囲が変わります。

標準 FMOD XArkMidiEngine を標準搭載 配布 codec プラグインは SRLA / WMA

標準的な音声形式

カテゴリ主な拡張子備考
一般音声.mp3 .mp2 .wav .ogg .flac .aiff .aifFMOD の標準再生対象です。
Windows Media 系.wma .asf .asx .waxOS 側のコーデック環境に影響を受けます。
FMOD バンク.fsbFMOD Sound Bank を再生できます。
プレイリスト / シート.m3u .m3u8 .pls .cueアプリ側で解釈し、プレイリストとして展開します。

トラッカー / MIDI / codec プラグイン

分類主な拡張子備考
トラッカー.mod .s3m .xm .it .mo3 .umx .669 .mtm一部は通常音声とロード方式が異なります。
MIDI.mid .midi .rmi .kar .dls標準搭載の XArkMidiEngine.dll を含む利用可能レンダラーで扱います。
配布 codec プラグインSRLA WMA配布版に含まれる codec プラグインはこの 2 種のみです。
追加 codec について: 配布版に含まれない codec プラグインを使いたい場合は FMOD-PLUGINS の GitHub Actions から必要なものをダウンロードしてください。

エフェクト群は設定画面の「エフェクト」ツリーから個別に開きます。各エフェクトはオンオフとプリセット操作に対応しています。

Chorus厚みや広がりを加えるMix, Rate, Depth
Echo反響を加えるDelay, Feedback, Dry/Wet
Flangerうねり感を加えるMix, Rate, Depth

高度な再生機能

普段使いで差が出るのは、ReplayGain、クロスフェード、NonStopMix、AB リピートです。

ReplayGain

ファイルに埋め込まれた ReplayGain タグを使って、曲ごとの音量差を補正します。トラック と アルバム の 2 モードがあり、さらにプリアンプも加えられます。

クロスフェード

曲の切り替わりで前曲をフェードアウトしつつ次曲をフェードインします。再生設定で長さを秒単位で指定できます。

NonStopMix

曲末の実音終了位置を基準に次曲へ移る機能です。実装上、クロスフェードとは排他 の扱いです。

AB リピート

A で開始点、B で終了点、C で解除します。語学や採譜の用途で便利です。

組み合わせの注意: NonStopMix はクロスフェードと同時運用ではなく、切替制御の考え方が異なります。

一般設定

起動時の挙動、ファイルを開いたときの扱い、Discord Rich Presence をまとめて調整します。

項目内容
前回のプレイリストを復元する前回終了時のプレイリストを起動時に戻します。
前回の再生位置から再開する途中停止した曲の位置を引き継ぎます。
プレイリストを自動保存する終了時にプレイリストを保存します。
常に最前面に表示するメインウィンドウを他のウィンドウより前に表示します。
ファイルを開いた時の動作再生開始か追加のみかを選択します。
Discord Rich Presence再生情報を Discord に表示します。アプリケーション ID の指定も可能です。

再生設定

聴感に直結する設定です。迷ったら ReplayGain とクロスフェードだけ先に見てください。

クロスフェード

  • 有効 / 無効の切替
  • フェード時間の指定

NonStopMix

  • 有効 / 無効の切替
  • 次の曲を事前準備してギャップレス再生
  • クロスフェードと排他

ReplayGain

  • 有効 / 無効
  • トラック / アルバムの切替
  • プリアンプ値の調整

おすすめの使い方

  • 配信や寄せ集め再生: ReplayGain はトラック
  • アルバム通し聴き: ReplayGain はアルバム
  • 曲間を自然にしたい: NonStopMix を試す

表示設定

表示設定はスキンの完全置換ではなく、スキンに上書きする調整欄として考えると分かりやすいです。

  • スペクトラムのモード、更新間隔、SnowBlock 落下速度
  • ウェーブ L / R、バー色、ウェーブフォーム色
  • タイトル文字、時間表示のフォント、サイズ、太字
  • タイトルスクロール間隔
  • 設定値をスキンより優先する各種オプション

出力設定

出力方式、デバイス、バッファ、MIDI レンダラー、サウンドフォントを管理します。

方式用途
AUTODETECT通常はこれが第一候補です。
WASAPIWindows 標準の扱いやすい低遅延出力です。
ASIOASIO 対応デバイス向け。反映タイミングに注意が必要です。
WINSONICWindows Sonic を使う構成です。
  • ストリームバッファ
  • DSP バッファサイズ
  • DSP バッファ数
  • MIDI レンダラー: FMOD / XArkMidiEngine / FluidSynth / BASSMIDI
  • XArkMidiEngine は標準搭載です
  • サウンドフォント対応: FMOD は .dls、XArkMidiEngine は .dls / .sf2、FluidSynth / BASSMIDI は .sf2

スキン

スキン設定では .xsk ファイルを選択し、メタ情報を確認して適用できます。 表示設定とは別系統で、UI 全体の見た目に関わる変更です。

  • スキンファイルの参照
  • Name / Author / Description の確認
  • 適用ボタンで切替

CDDB

CD のメタデータ問い合わせ先を管理します。複数サーバー登録と優先順位設定が可能です。

  • 問い合わせ URL の追加 / 削除 / 並べ替え
  • gnudb / FreeDB 優先か MusicBrainz 優先かの切替
  • デフォルト設定への復帰

プラグインと関連付け

ここでは「再生機能を増やす」と「Windows 上でこのアプリを既定プレイヤーに近づける」を分けて考えます。

プラグイン

  • 配布版に含まれる codec プラグインは SRLA と WMA のみです
  • 他の codec プラグインは FMOD-PLUGINS の GitHub Actions から取得してください
  • ロード済みプラグイン一覧を確認できます
  • 状態、種別、バージョンを確認できます
  • 再スキャンで検出を更新できます

関連付け

  • 対応形式の一覧を見ながら登録 / 解除を行います
  • 管理者権限が必要なケースでは再起動導線があります
  • MIDI は利用中レンダラーに応じて表示情報が変わります

CD

オーディオ CD を扱うための専用画面があります。読み込み、再生、プレイリスト追加、メタデータ取得が中心です。

  1. CD をドライブへ入れます。
  2. CD 画面でドライブを選びます。
  3. TOC が読めたら、トラック一覧の確認とプレイリスト追加ができます。
  4. CDDB や MusicBrainz の問い合わせで曲名やアルバム情報を補完できます。

CUEシート

.cue を開くと、1 つの長い音声ファイルを複数トラックとしてプレイリストへ展開できます。

  • シングルファイル型、マルチファイル型の両方を扱えます
  • 展開後は通常のプレイリスト項目として再生できます
  • 連続録音系のアルバム再生やライブ盤管理に向いています

MIDI

MIDI は利用するレンダラーによって再生品質と挙動が変わります。X-Ark では標準搭載の XArkMidiEngine を含め、利用可能なライブラリに応じてレンダラーを切り替えられます。

FMOD

追加ライブラリがなくても使える基本経路です。サウンドフォントは .dls に対応します。

XArkMidiEngine

標準構成でも選択できる MIDI レンダラーです。サウンドフォントは .dls と .sf2 に対応します。

FluidSynth

fluidsynth.dll が使える環境では、.sf2 を用いた MIDI 再生が可能です。

BASSMIDI

bass.dll と bassmidi.dll があれば利用できます。サウンドフォントは .sf2 に対応します。

SoundFont

利用できる形式はレンダラーごとに異なります。FMOD は .dls、XArkMidiEngine は .dls / .sf2、FluidSynth と BASSMIDI は .sf2 を使用します。

困ったとき

よくある詰まり方を先にまとめます。

症状確認ポイント
音が出ない出力設定のデバイス、出力方式、音量を確認してください。
MIDI が鳴らない利用中レンダラーと、指定したサウンドフォント形式がそのレンダラーに対応しているか確認してください。追加 DLL を使う構成では配置状況も確認してください。
追加 codec の形式が開けない必要な codec プラグインが配置されているか、配布版同梱外のものは FMOD-PLUGINS の GitHub Actions から取得したか確認してください。
CD 情報が取れないCDDB 設定の優先順位、ネットワーク到達性、ディスク情報の読み取り状態を確認してください。
曲間が不自然クロスフェードと NonStopMix のどちらを使うか整理してください。
このファイルは構成、導線、実装との整合性を重視して作成しています。
